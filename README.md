# 📚 Лиза — Telegram-бот по Genshin Impact и «Осквернённому Граалю»

Лиза Минчи, библиотекарь Ордо Фавониус, отвечает на вопросы по Genshin Impact и по настольной
игре «Осквернённый Грааль» (Tainted Grail: «Падение Авалона», «Короли краха»)
(RAG: векторный поиск в ChromaDB + Claude API).

---

## 🏗️ Архитектура (docker-compose)

```
            ┌──────────────┐
            │  ipcheck     │  ipcheck.py — IP через прокси в ALLOWED_SUBNET? (exit 0/1)
            └──────┬───────┘
                   │ только при успехе
            ┌──────▼───────┐
Telegram ◄──┤  bot         │  bot.py — Лиза, ищет контекст и спрашивает Claude
            └──────┬───────┘
                   │ HTTP
            ┌──────▼───────┐
            │  chroma      │  chromadb/chroma, данные в ./chroma_db
            └──────▲───────┘
                   │ HTTP
            ┌──────┴───────┐
Fandom,  ──►│  updater     │  updater.py — при старте и раз в сутки: вики, Project Amber,
Amber,      └──────┬───────┘  paimon.moe
paimon.moe         └──► ./state/banners.json ──► bot (текущие молитвы и события)
```

| Файл | Назначение |
|------|------------|
| `bot.py` | Telegram-бот (персонаж и промпт — `SYSTEM_PROMPT`) |
| `updater.py` | Обновление базы при старте и раз в сутки |
| `src_amber.py` | Источник Project Amber: персонажи, таланты, созвездия, оружие, артефакты |
| `src_paimon.py` | Источник paimon.moe: молитвы и события |
| `src_tg.py` | «Осквернённый Грааль»: правила (PDF), путеводитель, лор → коллекция `tainted_grail` |
| `tainted_grail/` | PDF правил «Падение Авалона» и «Короли краха» (новые PDF кладите сюда) |
| `db.py` | Общее подключение к ChromaDB и многоязычные эмбеддинги |
| `ipcheck.py` | Проверка внешнего IP (сервис `ipcheck` и проверка внутри бота) |
| `xml_parser.py` | Разовая загрузка базы из XML-дампа вики (устарело, есть `updater.py --full`) |
| `parser.py` | Парсинг истории Telegram-чата в `knowledge_base.json` |

## 🔑 Ключи и настройки

Настройки — в `.env` (шаблон: `.env.example`), персональная часть промпта (кто есть кто
в чате) — в `prompt_private.txt` (шаблон: `prompt_private.example.txt`). Оба файла в git не попадают.

- `TG_BOT_TOKEN` и данные Telethon — в `.env`.
- `ANTHROPIC_API_KEY` — **из `~/.bashrc`** (переменная окружения хоста), запросы идут
  в `api.anthropic.com` через HTTP-прокси `ANTHROPIC_PROXY` (пусто — напрямую). Через прокси идёт только
  Claude API; Telegram, вики и проверка IP — напрямую.
  Compose не запустит бота, если переменная не задана.
- `CLAUDE_MODEL` — опционально, по умолчанию `claude-sonnet-4-5`.

## 🛡️ Ограничения доступа

**IP.** Claude API можно использовать только если внешний IP, с которым запросы выходят
через прокси `ANTHROPIC_PROXY`, принадлежит `ALLOWED_SUBNET` (обязательная переменная в `.env`; не задана — проверка не проходит).
IP определяется через ipify/ifconfig.me/icanhazip/ipinfo, Claude для проверки не используется.
Если хоть один сервис видит IP вне подсети или IP не определился — проверка не пройдена.
- сервис `ipcheck` запускается первым; не прошёл → падает, и compose не запускает бота;
- бот перепроверяет IP каждые `IP_CHECK_INTERVAL` секунд (300). При неверном IP он **не падает**:
  Claude не вызывается, а Лиза отвечает случайной фразой из `AKASHA_DOWN` в `bot.py`
  («Прости дорогой, но Акаша сейчас не доступен» и др.). Пока Акаша недоступен, проверка
  повторяется каждые `IP_RECHECK_INTERVAL` секунд (60), после восстановления IP бот снова отвечает;
- `parser.py` не запустится вне подсети.

**Прокси перед каждым запросом.** Перед каждым обращением к Claude бот проверяет, открывается ли
TCP-соединение с прокси `ANTHROPIC_PROXY` (таймаут `PROXY_CHECK_TIMEOUT`, 3 с). Если нет — Claude
не вызывается, Лиза отвечает фразой из `AKASHA_DOWN`. То же — если сам запрос к Claude не смог
подключиться.

**Чаты.** Лиза отвечает только в чатах из `ALLOWED_CHATS` (через запятую, по умолчанию `TG_CHAT`),
а в личке — только участникам этих чатов. Из чужих групп бот сразу выходит.

## 🚀 Запуск

Автозапуск отключён (`restart: "no"`), после перезагрузки сервера контейнеры
нужно поднять вручную:

```bash
source ~/.bashrc
docker compose up -d --build        # chroma + bot + updater
docker compose logs -f bot updater
docker compose down                 # остановить всё
```

## 🔄 Обновление базы

Сервис `updater` обновляет базу **сразу при старте** и затем раз в сутки в `UPDATE_TIME`
(UTC, по умолчанию `01:00` = 04:00 МСК). Источники обновляются независимо: ошибка одного
не мешает остальным, неудачная синхронизация повторяется через час.

| Источник | Что даёт | Как обновляется |
|----------|----------|-----------------|
| **Вики** (genshin-impact.fandom.com/ru) | статьи, включая данные инфобоксов (редкость, элемент, регион, дата выхода, баннер…) | по `recentchanges` только изменённые статьи; полностью — если прошлой синхронизации не было, она старше 30 дней или изменилась обработка статей (`WIKI_SCHEMA`) |
| **Project Amber** (gi.yatta.moe) | данные из файлов игры на русском: персонажи (профиль, таланты, созвездия), оружие (пассивки R1/R5), наборы артефактов; новые персонажи — в день выхода версии | целиком, но в базу записываются только изменившиеся документы |
| **paimon.moe** (данные из github.com/MadeBaruna/paimon-moe) | молитвы и события: актуальные — в `state/banners.json`, история молитв по персонажам/оружию и по версиям — в базу | целиком, в базу — только изменения |

| **«Осквернённый Грааль»** — отдельная коллекция `tainted_grail` | правила из PDF в `./tainted_grail/` (страницы-карты на английском отсеиваются), «Путеводитель по миру „Осквернённого Грааля“» Crowd Games (VK), лор вселенной — категория Lore вики *Tainted Grail: Conquest* (англ., тот же мир). Энкаунтеры не загружаются | целиком, в базу — только изменения |

Бот каждый раз прикладывает к вопросу блок «Сейчас в игре»: дату, текущие и следующие
молитвы и события из `state/banners.json`.

Состояние хранится в `./state/updater_state_<коллекция>.json`.

Ручной запуск:

```bash
docker compose run --rm updater python updater.py --once   # инкрементально
docker compose run --rm updater python updater.py --full   # то же, вики — полностью
docker compose run --rm updater python updater.py --once --only amber paimon   # выбранные источники
```

## 🔎 Выбор базы

Если в вопросе есть маркеры «Осквернённого Грааля» (Грааль, Авалон, менгир, искаженье,
«Короли краха», имена героев…), бот ищет в коллекции `tainted_grail`, иначе — в базе Genshin
(с блоком «Сейчас в игре»). Уточняющие вопросы без ключевых слов остаются в теме предыдущего
вопроса диалога; `/reset` сбрасывает и тему.

В чатах из `TG_PRIORITY_CHATS` любой вопрос считается вопросом
по «Осквернённому Граалю»; на Genshin бот переключается только по явным маркерам (Genshin, Тейват,
Паймон, примогемы, молитвы…). Лиза не переспрашивает, о какой игре речь.

## 💬 Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Приветствие |
| `/reset` | Очистить историю диалога в текущем чате |
| `/pray` | Молитва на текущем баннере персонажа (из paimon.moe). Только в чате `PRAY_CHAT_ID`. Шансы как в игре: 5★ 0,6% с мягкой гарантией с 74-й и жёсткой на 90-й, 4★ каждые 10, 50/50 со стандартными 5★. Счётчики у каждого свои, хранятся в `./botdata/pray.json`. Пользователям из `PRAY_BONUS_USERS` бонус: 10% на Джинн, даже если её нет в баннере. Работает без Claude |
| `/praystats` | Рейтинг молитв чата: больше 5★ — выше, при равенстве — кому они дешевле дались; плюс своё место и сколько до гарантии. Только в `PRAY_CHAT_ID` |
| `/delete` | Удалить последнее сообщение Лизы в этом чате (повторно — предыдущее). Только для `ADMIN_USERNAMES`. Telegram позволяет удалять сообщения не старше 48 ч; id сообщений хранятся в `./botdata`, поэтому команда работает и после перезапуска |
| (упоминание / ответ боту) | Вопрос Лизе; в личке — любое сообщение |

При старте бот сам меняет своё имя в Telegram на «Лиза» (`set_my_name`).

## ⚠️ Замечания

- Docker-сеть проекта с MTU 1350: часть трафика хоста идёт через VPN (`vpn0`, MTU 1354),
  с MTU 1500 TLS-соединения из контейнеров (например, к GitHub) зависали.

- `session_parser.session` хранит авторизацию Telethon — не делись им.
- `knowledge_base.json` содержит переписку — храни его приватно.
